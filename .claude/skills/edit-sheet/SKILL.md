# 編集指示書を作る手順

## 1. 読む
- `CLAUDE.md`
- `knowledge/editing.md`：字幕、素材、音声、カット、納品条件（**全部**読む）
- `knowledge/operations.md`：使える素材とツール
- `knowledge/ng-examples.md` の「B. 編集」
- 対象の台本と、そのレビュー（`reviews/`）

レビューが「要修正」のままなら、ここで止めて、そのことを返す。

## 2. 作る
1. **撮影リスト**：自撮り、ナレーション、手持ちの素材のどれを使うか
   - 無い素材は「要撮影」と書く
2. **カット表**：1行に1カット。秒、映像と素材、字幕、ナレーション、効果と音を書く
   - 字幕は1画面1〜2行。改行の位置も書く
   - 重要語を画面の端やUIの位置に置かない
   - 同じ説明の中では、同じ画像を出し直さない（1回出したら説明が終わるまで出したまま）
   - 言い直しのカットは、語尾や「っ」の後ろで切るよう指示する
3. **音声**：本人の声を使う。BGMは雰囲気だけ指定し、曲名は【要確認】とする
4. **参考動画がある場合**：真似したい要素を、次の項目に分けて書く
   - 字幕の位置
   - カットの間隔
   - 冒頭の見せ方
   - BGMの雰囲気
   - 色や文字の装飾
5. **カバー案**を2つ
6. 合計の秒数が台本と合っているか確認する

## 3. 出力
`outputs/edit/YYYY-MM-DD_テーマ_edit.md`
```
# 編集指示：<テーマ>（CapCut／Canva）
## 撮影リスト
## カット表
| # | 秒 | 映像・素材 | 字幕（1〜2行・改行位置） | ナレーション | 効果・音 |
## 参考動画から真似する要素（あれば）
## カバー案（2つ）
## 要撮影・要確認
## 本人の書き出し前チェック（editing.md の「5. 納品条件」を写す）
```
