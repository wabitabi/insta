# 数字を集計する手順

## 1. 読む
- `CLAUDE.md`
- `knowledge/metrics.md`：定義、集計期間、比較方法（**全部**読む）
- `inputs/insights/` のCSV
- 対象期間の企画（`outputs/plans/`）

## 2. データを確認する
- 期間、行の数、空欄の列を書き出す
- **データが無ければ、ここで止めて「データ未入力」と返す。** 数字を推測で作らない
- 空欄は「未入力」として扱う。0とは扱わない

## 3. 集計する（`metrics.md` の定義と期間に従う）
1. KPI：DM件数、問い合わせ件数（窓口別、合言葉別）
2. 目標と比べる：月30件。週次なら週7件ほどのペース（計算値）と比べる
3. 投稿別：7日後の数字で、同じ形式どうしで比べる
4. テーマ（A〜H）別、合言葉別に、問い合わせを並べる
5. 同じ形式の投稿が5本未満なら「傾向の参考」と書き、断定しない

## 4. 出力
`outputs/analytics/YYYY-MM-DD_期間_report.md`
```
# 分析：<期間>（週次／月次）
## データの状態（期間、件数、未入力の項目）
## KPI（DM件数／問い合わせ件数／目標との差）
## 投稿別の表（数字の出所のファイル名つき）
## 分かったこと（事実）
## 考えられる理由（【仮説】と明記）
## 次にやること（3つまで。企画担当に渡す形）
## 足りないデータ
```
