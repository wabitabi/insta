# 避けること・チェックルール

## 本人が避けたいもの
| 種類 | 内容 |
|---|---|
| 表現 | **煽り**（例：「今すぐ行かないと損」「知らないとヤバい」「◯◯しないと一生話せない」） |
| 表現 | **他社や他の国を下げる比較**（例：「◯◯国はやめとけ」「他のエージェントは高いだけ」） |
| 企画 | 特になし |
| 編集 | **AI感**（機械音声、AIっぽい定型文、不自然な生成画像、テンプレ感の強いテロップ） |

## 「AI感」を出さないための目安
- 「〜について解説します」「いかがでしたか？」「結論から言うと」「〜と言えるでしょう」を多用しない
- 3つ並べるだけの抽象的なまとめにしない。本人の具体的な体験や場面を1つ入れる
- 声は本人のナレーションか自撮りを基本にする（機械音声は使わない）
- 素材は本人が撮った写真や動画を優先する

## 事実・法令まわり
- 費用、為替、ビザ、学校の情報は変わる。**出典と確認日**を付け、断定しない（「〜時点で約◯円」）
- 「絶対」「必ず」「誰でも」「◯週間でペラペラ」など、成果を保証する言い方をしない（景品表示法の優良誤認・有利誤認を避ける）
- 特定の学校や他社の名前を出して評価しない。出すときは本人の確認を取る
- 写っている他人や学校の撮影許可が要る素材は「要確認」とする
- 本人の経験として語れる範囲は `knowledge/profile.md` に従う
