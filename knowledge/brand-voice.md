# 口調と見本

## 基本
- 一人称：**私**
- タメ口、明るい、フレンドリー
- 熊本出身（熊本弁を使うかは**未設定**。勝手に方言を入れない）

## 見本：本人の過去のリール（ベトナムのアヒルスポット）
全文は `inputs/past-posts/2026-10-11_vietnam-duck-reel.md`。読み取れる特徴は次の通り。

| 特徴 | 例 |
|---|---|
| 冒頭に囲みのフックを入れる | `\ SNSでバズってる /` |
| 冒頭で保存を促す | 「〜行く人は保存しておいてね！」 |
| 短いテロップで、体験を時系列に実況する | 「予約なしで突撃」 |
| 実用情報を途中に挟む | 「約600円で体験できる」「帽子は無料で借りれたよ」 |
| 「笑」「ww」「、、」でゆるいツッコミを入れる | 「マッサージと言うより襲われてる、、笑」 |
| 具体的なアドバイスを入れる | 「汚れても良い服で行くのがおすすめ」 |
| 最後にもう一度保存を促す | 「保存して行ってみてね！！」 |
| 詳細はキャプションに回す | 「※場所はキャプションへ」 |

→ 留学の投稿でも、この**テンポ、実況感、実用情報、保存の呼びかけ**を土台にする。
→ 留学の投稿では、最後の行動を「保存」から「**相談はDMで**」に変える回も作る（問い合わせKPIのため）。
