## 2. 数字の定義

### 最優先（KPI）
| 指標 | 定義 | 数え方 | 区分 |
|---|---|---|---|
| **DM件数** | 留学の相談や質問を目的としたDMの**人数** | 合言葉（「セブ」「マルタ」など）のDMと、合言葉なしの相談DMを分けて数える。あいさつだけ、営業、スパムは数えない | 【提案】 |
| **問い合わせ件数** | 相談の申し込みとして成立した**人数**（DM、公式LINE、Googleフォームの合計） | 同じ人が複数の窓口から来たら1人と数える。どの窓口・どの投稿から来たかをメモする | 【提案】 |

### 補助（問い合わせにつながったかを説明するための数字）
インサイトの指標名は、本人の画面に表示されている名前に合わせる【要確認】。
| 指標 | 見る理由 |
|---|---|
| 再生数／閲覧数 | どれだけ届いたか |
| リーチ（届いたアカウントの数） | 新しい人に届いたか |
| 保存数 | 後で見返したいと思われたか |
| シェア数 | 人に教えたいと思われたか |
| プロフィールへのアクセス | 投稿からアカウントに興味を持ったか |
| リンクのタップ（LINE・フォーム） | 問い合わせ窓口まで来たか |
| フォロー数（その投稿から） | 継続して見たいと思われたか |

- 「保存やシェアが多い投稿は問い合わせにつながりやすい」という考え方は【仮説】。データで確かめる

## 3. 集計期間【提案】
| 単位 | 期間 | 使い方 |
|---|---|---|
| 投稿ごと | 投稿から**7日後**の数字で比べる | 投稿どうしを同じ条件で比べるため |
| 週次 | 月曜〜日曜（日本時間） | 企画の見直し（週7件ペースと比べる） |
| 月次 | 暦の月（1日〜末日） | 目標（月30件）と比べる |

- 7日後に数字を取り忘れたら、取った日を記録して「7日後ではない」と明記する

## 4. 比較方法【提案】
1. **同じ形式どうしで比べる**（リールはリール、カルーセルはカルーセル）
2. **同じ経過日数で比べる**（7日後どうし）
3. **自分の過去と比べる**：同じ形式の投稿が5本以上たまったら、その中央値を基準にする。それまでは件数が少ないので「傾向の参考」とし、断定しない
4. **テーマ（悩みA〜H）別、合言葉別**に、問い合わせ件数を並べる
5. 他のアカウントの数字とは比べない（データが無いため）
6. 1回に変える要素は、なるべく1つにする（冒頭、尺、CTAなど）。何が効いたかを分けるため【仮説】

## 5. データの置き方
`inputs/insights/YYYY-MM.csv`（Googleスプレッドシートから書き出す）

```
投稿日,形式,テーマ(A-H),合言葉,7日後の取得日,再生数,リーチ,保存,シェア,プロフィールアクセス,リンクタップ,フォロー,DM件数,LINE経由,フォーム経由,問い合わせ件数,メモ
```
- 書いていない数字は空欄にする（0と書かない。0は「本当に0件」の時だけ）
- 週次・月次の集計の手順：`.claude/skills/metrics-report/SKILL.md`
